# Governance

PulseRN is maintained in public by the repository maintainers. Product decisions prioritize secure,
local-first React Native debugging, compatibility, and evidence from reproducible user workflows.

- Bugs belong in Issues; setup questions and proposals belong in Discussions.
- Maintainers aim to acknowledge reproducible bugs and review focused pull requests promptly.
- Public API changes require tests, documentation, compatibility consideration, and maintainer review.
- Security reports must use GitHub private vulnerability reporting.
- Maintainers may appoint recurring contributors after sustained, constructive participation.
- Release notes credit external contributors and link their merged work.

Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md).
