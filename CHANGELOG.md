# Changelog

GitHub Releases are the canonical PulseRN desktop changelog and are generated from merged pull
requests with the categories in `.github/release.yml`.

- [Desktop release notes](https://github.com/maahibhama/PulseRN/releases)
- [SDK versions on npm](https://www.npmjs.com/package/@pulse-rn/sdk?activeTab=versions)

Breaking SDK or protocol changes must be called out explicitly in the corresponding release notes.
