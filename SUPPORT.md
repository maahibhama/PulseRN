# Support

PulseRN is a community-maintained open-source project.

- Use [GitHub Discussions](https://github.com/maahibhama/PulseRN/discussions) for setup questions,
  integration help, and usage guidance.
- Use [GitHub Issues](https://github.com/maahibhama/PulseRN/issues) for reproducible defects and
  focused feature proposals.
- Follow [SECURITY.md](docs/SECURITY.md) for private vulnerability reporting. Never place secrets,
  pairing credentials, captured archives, or private application data in a public issue.

Preview releases are best-effort and may require manual upgrades. Maintainers do not provide an
SLA, guaranteed response time, or private implementation support.
